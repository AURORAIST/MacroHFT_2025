# 问题 08: 执行损失模型未体现 C(|ΔP|)

## 问题描述

论文中执行损失包含 C(|ΔP|) 相关项。当前环境实现中 fill_cost 直接返回 0，仅包含佣金项。

## 可能修复方案

1. 基于盘口深度近似实现 C(|ΔP|)（推荐）
- 从状态中恢复可用的 bid/ask 深度或价差代理。
- 定义冲击成本函数，如 slippage = k1 * |ΔP| + k2 * |ΔP|^2。

2. 固定比例滑点模型
- 若无可靠盘口字段，使用常数或波动率相关滑点。

## 推荐修改位置

- src/env/trading_env.py（compute_fill_cost, compute_execution_cost）

## 原因与收益

- 提高奖励函数与论文金融设定的一致性。
- 减少策略过度交易倾向。

## 风险与代价

- 需要校准新参数，否则会改变收益规模。
