# 问题 02: Phase II 未真正使用示范 chunk 监督

## 问题描述

当前 Phase II 的训练主循环以环境状态为主，未形成明确的 demo chunk 到训练样本的一一监督路径，因此与论文中的示范一致性约束不完全一致。

## 可能修复方案

1. 双流训练（推荐）
- 环境交互流: 负责 r_sel 的 RL 优化。
- 示范监督流: 同步采样 demo chunk，提供 gt_label 做 KL/CE 约束。
- 两种损失加权求和。

2. 纯环境流 + 周期性示范蒸馏
- 每 N 步在 demo 集上做一次监督微调。

## 推荐修改位置

- scripts/train_phase2.py（训练循环拆为两部分）
- src/data/dataset.py（增加 demo batch 采样接口）

## 原因与收益

- 保证模型既优化真实收益，也保持与示范分布的对齐。
- 防止 KL 约束退化为无效项。

## 风险与代价

- 训练流程更复杂，需要调节损失权重。
